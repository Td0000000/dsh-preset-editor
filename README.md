# dsh-preset-editor（预设编辑）

给 DSH NEXT 用的 Agent 预设编辑器：可视化做预设、给聊天提前填好提示词和消息模板，按工作目录自动套预设、按预设自动套模型。一切只是为了方便：少手动选几次，某些固定任务让 AI 一开局就进入状态。

> 适配 DSH NEXT `2.0.22-next`（内核 DeepSeek Harness `0.2.2-rc.3`）；当前版本 `1.11.0`。

> **1.11.0 修复（数据安全）**：
> ① 删除预设会**级联清理**指向它的目录规则与模型绑定——旧版不清理，残留规则会让「项目默认」整表永远保存失败，且重建同 ID 预设后旧规则会静默复活；
> ② 新建预设时 ID 撞车**不再静默覆盖**旧预设（返回 409，UI 让你选「另存为」或「明确覆盖」）；
> ③ 存储文件里无法加载的坏条目**不再被静默删除**，改为读取时收集、写回时原样保留，需在 UI 里显式清理；
> ④ 所有「读-改-写」放进同一条串行队列，修掉并发保存互相覆盖丢预设；
> ⑤ 外部直接改写存储文件、system 含非法模板变量（如 `{{cwd}}`）的预设拒绝挂载并上报诊断，不再等到运行时才炸；
> ⑥ 删除不存在的预设返回 404；单预设导入默认不覆盖已有预设。


灵感源自 [Rain-kl/dsh-preset-plus](https://github.com/Rain-kl/dsh-preset-plus)，感谢原作者的开源分享。

## 能做什么

**1. 预设编辑**——可视化创建、修改、导入导出自定义预设。每个预设都会注册进 DSH 官方预设体系，直接出现在设置页【自定义预设】和新会话右上角的预设选择器里，和官方预设一样用。

**2. 聊天模板填充**——每个预设 = system 人格 + user / assistant 开场消息 + 一套 AI 工具。固定套路的活（翻译、重构、客服话术……）把提示词和开场白写进预设，新会话选一下就行，不用每次复制粘贴。user / assistant 条目走请求级注入，不进会话日志，不会被压缩摘要掉。

**3. 按工作目录指定默认预设**——在「设置 → 预设编辑 → 项目默认」里给不同项目文件夹配默认预设（含官方内置预设），新建会话按工作目录自动套用。规则默认包含子文件夹（就近优先，可单条关闭）；有总开关，逐条可启停；不改 DSH 官方默认；用户手动选的永远优先。

**4. 按预设指定默认模型**——每个预设（自定义或官方内置）可绑定默认上游模型 + 思考强度，用该预设的会话自动套用，只写当前会话，不改全局默认；用户手动改过模型的不覆盖。

## 安装

仓库根目录附带编译好的安装包，直接装，不用编译：

```text
请帮我把这个 DSH 插件装到当前 DSH profile：

1. 克隆仓库到本地任意目录：git clone https://github.com/Td0000000/dsh-preset-editor.git
2. 用 DSH 的 plugin_manager 工具执行 install_bundle，target 传仓库根目录里 tgz 的绝对路径，
   例如 <克隆目录>/dsh-preset-editor-1.11.0.tgz
3. 看到结果里 application=applied 后重启 DSH NEXT，
   设置页左侧应出现【预设编辑】入口。
```

开发者也可直接用源码目录安装（`install_bundle` 的 target 传目录绝对路径）。

## 用法

- **新建预设**：「预设编辑 → 新建预设」，填系统提示词、加 user / assistant 消息条目、勾 AI 工具，保存后新开对话选它即可。system 只支持 `{{model}}` / `{{provider}}` 两个变量（写别的保存时会被拦）。
- **项目默认预设**：「预设编辑 → 项目默认」，填项目文件夹绝对路径、选预设、点加入规则，保存。总开关控制整体，每条规则可单独启停。
- **默认模型**：「当前预设」页下方的「默认模型与思考强度」区（自定义和官方预设都在这设），或编辑页底部设置。模型列表实时取自 DSH 已配置的上游。

---

## 数据位置

- 全部存在 `$DSH_HOME/preset-editor.json`（`$DSH_HOME` 默认 `~/.dsh`）：`presets`（自定义预设）、`presetModels`（官方预设的模型绑定）、`projectDefaults`（目录规则）。
- 导入 / 导出 JSON 可备份迁移；旧版 `$DSH_HOME/.agent-presets/` 目录仅做一次性迁移。

---

## 注意

- 预设只在空白会话（没开始第一轮）生效；子代理 / fork 派生会话不受目录规则影响。
- 禁用本插件后，它注册的自定义预设会一并消失。
- 更新插件后需要重启 DSH NEXT 才会生效。
