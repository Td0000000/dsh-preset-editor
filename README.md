# dsh-preset-editor（预设编辑）

DeepSeek Harness 官方自定义预设可视化编辑插件。

支持对自定义 Agent 预设进行可视化创建、编辑、管理与导出导入，支持 `SYS`（系统提示词）、`USER`（用户引导/约束）、`ASSISTANT`（助理回复伪装前置）三类消息自由调序与编排，配备全套官方与扩展 AI 工具选择，完全遵循并融入官方 Agent 预设体系，新会话一键选择即可默认自动注入。

---

## 🌟 核心特性

1. **完全符合官方自定义预设规范**
   - 建立的每一个预设均直接在 `<dshHome>/.agent-presets/<id>/` 写入标准的 `preset.yml` 与 `agent.cordis.yml`。
   - 无缝呈现在官方设置的【自定义预设】以及右上角【Agent 预设选择器】中。
2. **纯粹的预设绑定触发（零命令、无感注入）**
   - 彻底移除了任何 `/` 前缀命令。
   - 只要在新建聊天时选择了对应的自定义预设，系统便会在启动会话与模型流式生成时默认自动注入该预设的提示词与上下文消息。
   - **精确隔离**：只对自己编辑绑定的自定义预设生效，官方内置预设（standard、minimal、ptc、cordis 等）保持纯净，绝不受任何影响。
3. **可视化三类型消息编排**
   - 支持 `SYS`（系统提示词）、`USER`（用户消息引导/破限）、`ASSISTANT`（助理前置伪装种子）三种消息类型。
   - 支持在界面上通过 ↑ 上移 / ↓ 下移按钮自由调整消息在上下文中的排列位置与执行顺序。
   - 每条条目支持独立启用/停用开关、实时内容修改与删除。
4. **AI 工具自由配备**
   - 点击【AI 工具】按钮，展示当前预设需要配备的所有工具（涵盖官方所有内置工具：Bash、PowerShell、文件操作、文件检索、替换编辑器、后台任务、网页检索、技能系统、询问用户、Todo 待办、子代理等，以及已安装的自定义工具）。
   - 自由勾选需要的工具，自动生成纯净高效的 `agent.cordis.yml` 组合配置。
5. **清晰规范的三大页面视图**
   - 顶部醒目大字：**预设编辑**，配以小字介绍。
   - 横向排版三大导航入口：
     - **当前预设**：卡片式浏览已创建的自定义预设，快捷进行编辑、导出、删除。
     - **新建预设**：定制新预设，配备工具与消息条目，操作仅有“保存预设”与“取消”。
     - **导入预设**：点击直接调起文件选择器，一键导入已有的预设 JSON 文件。
     - **编辑预设**：支持对已存在的预设修改内容、配备工具、支持“保存”、“取消”、“删除预设”与“导出预设”。

## 📦 安装方式

在已配置好 DSH 环境的终端中运行：

```bash
# 进入 profile 所在的 DSH 配置环境安装
dsh plugin --profile web add link:./plugins/dsh-preset-editor
```

安装后启动或重启 DSH Web 服务：

```bash
./dshw start
```

打开设置页面，在左侧导航栏点击【预设编辑】，即可开始管理与创建自定义预设。

## 🛠️ 数据结构与技术原理

### 1. 存储与目录结构

- 插件配置文件：`~/.dsh/preset-editor.json`，保存全部自定义预设的提示词模板、启用状态与工具列表。
- 官方预设目录映射：`~/.dsh/.agent-presets/<id>/`
  - `preset.yml`：官方预设显示名称与描述。
  - `agent.cordis.yml`：基于用户勾选配备的 AI 工具动态生成的 Cordis 插件组合。

### 2. 注入时机

- **SYS 提示词注入**：通过 `ctx.systemPrompt.section()` 注册动态提示词段落。当会话 Agent 运行时，动态读取该预设中所有启用的 `SYS` 条目合并注入；并在 `system-prompt/assemble` 中优化冗余 identity，保证提示词纯粹性。
- **USER / ASSISTANT 伪装消息注入**：通过 `ctx.llm.stream` 拦截钩子，在会话首轮对话模型交互前，将预设中启用的 `USER` 和 `ASSISTANT` 消息转换为标准上下文消息前置注入，不污染全局历史，达到预填充与引导效果。
- **非自定义预设跳过**：当会话使用的是非本插件管理的预设（如 standard 预设）时，拦截器直接放行，保证官方预设的原生表现。
